# FAQ

## Does the port include the original game?

No. The original game's content is separate from the Vita port.

## Where do I get the original game?

Use the official [Steam listing](https://store.steampowered.com/app/698780/Doki_Doki_Literature_Club/).

## What is the required content path?

The current README does not specify a title-ID path. Check the exact release instructions or ask in Issues; do not guess.

## Where should I report a problem?

Open an issue in the [port repository](https://github.com/SilverCrow2323/Magical-Literary-Heroine-Natsuki-Saves-The-Literature-Club-Vita/issues). Include the release version and reproducible steps, not copyrighted game files.
