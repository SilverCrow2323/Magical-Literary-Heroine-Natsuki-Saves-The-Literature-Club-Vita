# Installation notes

The current README describes the port's technical origins and links the original game and mod homepage, but it does not specify a complete VPK install sequence or title-ID path.

## Before installing

1. Check [GitHub Releases](https://github.com/SilverCrow2323/Magical-Literary-Heroine-Natsuki-Saves-The-Literature-Club-Vita/releases) for a published VPK and release-specific instructions.
2. Obtain the original Doki Doki Literature Club game from [Steam](https://store.steampowered.com/app/698780/Doki_Doki_Literature_Club/).
3. Obtain the mod from its [homepage](https://www.mlhnstlc.com/).
4. Read the exact release notes before copying any game files.

> [!IMPORTANT]
> **MUST KNOW!!** Do not assume a title-ID path from another Ren'Py Vita project. The current README does not list the path for this port.
